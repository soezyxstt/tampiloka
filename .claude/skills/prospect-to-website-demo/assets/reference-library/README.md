# Referensi café dan resto per section

91 gambar berbeda · 38 referensi · seluruh 11 template awal · 14 folder klasifikasi.

## Mulai di sini

1. Ekstrak seluruh ZIP ke satu folder.
2. Buka **INDEX.html** melalui browser. Indeks dan gambar dapat ditelusuri tanpa koneksi internet.
3. Gunakan filter section dan kolom pencarian untuk membandingkan beberapa sumber.
4. Klik gambar untuk membuka ukuran penuh; tautan sumber eksternal memerlukan internet.

## Isi paket

- **INDEX.html** — indeks visual dengan pencarian dan filter section.
- **REFERENSI_DAN_SUMBER_GAMBAR.md** — bank referensi per section, enam resep kombinasi proyek, seluruh 11 template awal, dan sumber setiap gambar.
- **00–12 serta 99** — folder gambar berdasarkan bagian landing page; setiap folder memiliki **SUMBER.md**.
- **MANIFEST_GAMBAR.json** — metadata, dimensi, klasifikasi, URL asli, dan checksum file.

Ada **109 file gambar** dalam folder karena **18 gambar** yang memuat lebih dari satu bagian disalin ke dua folder yang relevan. Tampilan “Semua gambar” di indeks menampilkan **91 gambar berbeda** tanpa pengulangan.

Preview template, screenshot, dokumentasi studio, mockup, papan UI, foto konten, serta artwork diberi label. Tahun arsip dicatat bila tersedia. Tanggal riset/pengunduhan: **22 Oktober 2026**.

Gambar disertakan dalam format yang berhasil diunduh dari sumber (JPEG, PNG, WebP, AVIF). Indeks menggunakan file lokal asli. Kredit dan tautan sumber tersedia pada setiap entri.
