# Bumi Upi — local concept

Standalone Next.js demo researched from the official @bumiupi profile and both PDF menus linked by https://linktr.ee/bumiupi.

`bun install`, then `bun run dev`: http://127.0.0.1:3017.

`bun run build`, `bun run lint`, `bun run typecheck`, `bun run check:demo`.

116 unique offerings; shared breakfast/regular items deduplicated. Roti Bakar Kornet Keju preserves different breakfast/regular prices. Product images cropped from official PDFs; house photographs from Momopururu's May 2026 visit with original watermarks retained. Source archive and normalized manifests are in research/ and research-bundle.json. Runtime uses local fonts/images and official shadcn/Base UI primitives.

Independent concept, noindex, loopback server only. Asset permissions and prices still require owner confirmation before publication. No booking form, payment, outreach, push, or deployment.
